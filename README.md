# Bộ Tool Sinh Viên

Người dùng chỉ cài `student-tools-loader.user.js`.

- Mở Facebook: chạy Facebook V5.
- Mở đúng Google Form Hành Động Đẹp: chạy bảng gửi biểu mẫu V2.4.

## Điều khiển từ xa

Sửa `status.json` rồi commit:

- `facebookEnabled`: bật hoặc tắt Facebook V5.
- `hanhDongDepEnabled`: bật hoặc tắt Hành Động Đẹp.

Hai repository cũ được giữ lại để dự phòng. Người đã chuyển sang Loader chung chỉ chịu sự điều khiển của `status.json` trong repository này.
